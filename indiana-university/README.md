# Indiana University Logo

3D printable Indiana University logo badge. Designed to be used by a relative as a mold for candles or air fresheners or something like that.

## What It Does

Imports the official IU logo SVG and extrudes it to create a printable 3/3 version

## Specifications

| Property  | Value      |
| --------- | ---------- |
| Width     | 50mm       |
| Thickness | 19mm       |
| Format    | SVG to STL |

## Customization

Edit `indiana-university.scad` to adjust:

- `target_height` - overall size (default 50mm)
- `thickness` - badge depth (default 19mm)
