# Changelog

## [1.0.0] - 2026-01-18

### Added

- Initial release of Arca Swiss Plate + Multiboard Peg adapter.
- Parametric Arca Swiss dovetail plate.
- Integration with imported multiboard `25mm-push-fit-peg.stl`.
- Side-profile extrusion design for optimal 3D printing orientation/strength.

### Technical Details

- **Plate dimensions**: 38mm × 32mm × 13.5mm (bottom × top × length to match peg).
- **Resolution**: `$fn = 100` for smooth surfaces.
- **Peg alignment**: Centered at plate midpoint
