# Changelog

## [0.1.0] - 2026-02-22

### Added
- Initial design
- Two side-by-side USB-C receptacle slots with USB-IF spec dimensions
- Stepped cavities: metal tip slot (8.34x2.56mm) + merged overmold pocket (12.35x6.5mm)
- Hemispherical grip nubs for compliant friction retention
- Entry and step chamfers for smooth insertion and reduced overhangs
- Integrated keyring lug with hull taper from body
- Parametric texture ridges wrapping all faces
- Optional cap with ceiling fillets
- Full parametric control over all dimensions, tolerances, and features
