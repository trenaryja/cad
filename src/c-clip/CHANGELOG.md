# Changelog

## [1.0.0] - 2026-02-01

### Added

- Initial release of parametric C-clip.
- Configurable target thickness, tolerance, and fabric gap.
- Independent front and back arm lengths.
- Three texture types: smooth, ridges, teeth.
- Per-face texture control (type and depth).
- Spring angle parameter for back arm compression.
- Rounded corners via fillet parameter.

### Technical Details

- **Default dimensions**: 25mm target, 50mm width, 3mm wall.
- **Texture spacing**: 2mm between features.
- **Print orientation**: Flat with C-opening up, no supports.
