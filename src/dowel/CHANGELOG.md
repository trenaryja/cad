# Dowel Generator — Changelog

## [1.0.0] - 2025-02-07

### Added

- Core parametric dowel with configurable diameter and length
- Three cap styles: flat, hemisphere (with adjustable ratio), chamfer (with angle/depth)
- Knurl surface texture with three patterns: longitudinal, helical, diamond
- Ring grooves for glue retention (count, width, depth, spacing)
- Fold-flat print mode: two halves connected by thin bridges
- Tolerance parameter for fit adjustment
- Full nomenclature and documentation system
